# Task 6: KNN Classification on Iris Dataset

## Project Overview
This project implements the **K-Nearest Neighbors (KNN)** algorithm on the classic **Iris dataset**. The main goal is to classify iris flowers into three species (**Setosa, Versicolor, Virginica**) based on sepal and petal measurements. This project demonstrates the complete workflow of a machine learning task: data exploration, preprocessing, model training, evaluation, and visualization.

---

## Dataset
- **File Name:** `iris.csv`
- **Description:** The dataset contains 150 records with four features for each iris flower:  
  - Sepal Length (cm)  
  - Sepal Width (cm)  
  - Petal Length (cm)  
  - Petal Width (cm)  
- **Target Column:** `Species` (the type of iris flower)
